# Quality Mechanisms

This section documents the meteorological quality mechanisms used by WeatherXM to evaluate station telemetry and physical deployments.

## Current Mechanisms (Active)

- [**General QoD Description (QoD v3 & SPV)**](/weather-and-science/quality-mechanisms/general-qod-description): High-level overview of how WeatherXM evaluates weather data quality and station deployments.
- [**QoD v3 Full Documentation**](/weather-and-science/quality-mechanisms/qod-v3-documentation): Complete technical specification of the active **QoD v3** (`version 3.0.0`) engine — self-sanity checks, spatial neighbor cross-validation, elevation-safe synoptic pressure tracking, 2-day hysteresis state machine, and annotation reference.
- [**Station Photo Verification (SPV)**](/weather-and-science/quality-mechanisms/spv-full-documentation): Full documentation of the Station Photo Verification (SPV) mechanism for evaluating station deployments via installation photos.
