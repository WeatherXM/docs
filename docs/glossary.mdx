| Term | Description |
| --- | --- |
| Barometer | A device that measures atmospheric air pressure (barometric pressure). |
| Cell Capacity (CC) | The maximum number of weather stations eligible to earn daily base rewards within a single H3 cell. See [Cell Capacity](/rewards/cell-capacity). |
| H3 Cell | A hexagonal geospatial cell (resolution 7) from Uber's H3 grid used by WeatherXM to organize station coverage, Explorer maps, and Cell Capacity. |
| HectoPascals (hPa) | The SI unit for measuring atmospheric air pressure. Equivalent to millibars (mb). |
| Hygrometer | The instrument that measures relative humidity (RH), expressed as a percentage between `0%` and `100%`. |
| Millimetres (mm) | The unit used to measure accumulated rainfall (`1 mm` equals `1 kg/m²` or `1 L/m²` of water). |
| Proof of Location (PoL) | WeatherXM's daily algorithm verifying that a station's reported GPS location matches its declared installation site. See [Proof of Location](/rewards/proof-of-location). |
| Quality of Data (QoD v3) | WeatherXM's daily meteorological quality engine that scores station telemetry (`0–1`) using self-sanity checks, spatial neighbor cross-validation, and 2-day deployment hysteresis. See [Data Quality](/rewards/data-quality). |
| Rain Rate | The intensity of rainfall, measured in millimetres per hour (`mm/h`). |
| Relative Air Pressure | Absolute barometric pressure adjusted to sea level for the station's elevation. |
| Relative Humidity (RH) | The percentage (`%RH`) of water vapor present in air relative to saturation at the same temperature. |
| Station Photo Verification (SPV) | Human review of a station's 4 directional installation photos against WMO siting guidelines. See [SPV](/weather-and-science/quality-mechanisms/spv-full-documentation). |
| Ultra Violet (UV) Index | A linear international standard scale measuring sunburn-producing UV radiation (`0` at night, `8+` very high, `11+` extreme). |
| Wind Direction | The compass direction the wind is blowing **from**. |
| Wind Gust | The highest measured wind speed over a short sampling period (typically 10 minutes). |
| Wind Speed | The speed of horizontal air movement past the anemometer. |
