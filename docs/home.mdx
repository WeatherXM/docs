<h3>How WeatherXM works</h3>

Station owners deploy all-in-one, easy-to-install weather stations. Every reading is cryptographically signed at the source and location-verified by GPS, then scored daily by [QoD v3](/rewards/data-quality). Owners earn `$WXM` rewards for high-quality data, while businesses and developers use the verified network data through [WeatherXM Pro](/weatherxm-pro).
