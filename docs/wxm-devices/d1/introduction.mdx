## Next steps

You just got your station, or, you will soon!
Let's see what are the necessary steps in order to properly assemble, install, claim and enable it to send data in order to receive $WXM reward tokens.

### Check the box contents

Make sure that everything is in order and you're all set to proceed with station assembly.

<Link to="/wxm-devices/d1/contents">View Contents</Link>

### Assemble your weather station

Assemble all parts and make sure all sensors work as expected. For this step, **you will need 2 AA batteries that are not included in the box.**

<Link to="/wxm-devices/d1/assemble">View Station Assembly Instructions</Link>

### Install your weather station

This is one of the most important steps, as proper installation is key in order to collect valid weather data. For this step, **you will need a pole that is at least 2m/6.5ft and a way to secure it in place (both not included in the box).** Here you will also see the best practices on how to properly install the station according to WMO.

<Link to="/wxm-devices/d1/install-weather-station">View Station Installation Instructions</Link>

### Connect and claim station

Once you've finished with installation, you can connect your station to your WG1200 Gateway and claim them as your own in WeatherXM network. To do this, **you will need to download our WeatherXM app (<Link to="https://play.google.com/store/apps/details?id=com.weatherxm.app&hl=en&gl=US" target="blank">Android</Link> and <Link to="https://apps.apple.com/ie/app/weatherxm/id1629841929" target="blank">iOS</Link>).**

<Link to="/wxm-devices/d1/connect-and-claim">View Connect and Claim Instructions</Link>

### Add your ERC20 compatible wallet

In order to receive WXM rewards, you will need to connect an ERC20 compatible wallet which supports Arbitrum One Network. We have prepared a guide to do so using MetaMask (although it is not mandatory to use this).

<Link to="/mobile-app/wallet/add-edit-wallet-address#how-to-create-wallet-on-metamask">View Wallet Addition Instructions</Link>

## Features and Specifications

### WG1200 Gateway

- **Display:** 3.95" capacitive touchscreen (LVGL UI) with live weather tiles, 40-minute live sparklines, and a detailed dashboard displaying **Daily Min/Max Extremes** (`↓ min ↑ max`), cumulative daily rainfall, and peak wind gusts
- **MCU & Radio:** ESP32-S3 with SX1262 sub-GHz LoRa/FSK transceiver (868 / 915 / 923 MHz) and 2.4 GHz Wi-Fi + BLE
- **Onboard Sensor:** Integrated barometric pressure sensor
- **Security & Reliability:** Hardware cryptographic signing (ATECC608 / secure identity) and zero-wear `RTC_NOINIT_ATTR` SRAM retention for daily extremes and rain baselines (>98% NVS flash wear reduction)
- **Local Storage:** Built-in microSD card slot for asynchronous 5-minute weather history (`history_v1_YYYY_MM_DD.csv`) and station/GPS data-quality metadata (`metadata_v1_YYYY_MM_DD.csv`) logging, with automatic 24-hour chart hydration on boot
- **Local Web Console & REST API:** Built-in, gzip-compressed HTTP web dashboard (`http://<gateway-ip>/`) with mDNS auto-discovery (`_weatherxm._tcp`), **Home Assistant** integration, and a `/llms.txt` AI agent reference
- **Off-Grid Mesh Support:** Optional collision-free **Meshtastic** and **MeshCore** LoRa weather beacon broadcasting
- **Power & Updates:** Powered by USB-C (power adapter not included); Over-The-Air (OTA) and USB Web Serial ([flasher.weatherxm.com](https://flasher.weatherxm.com)) firmware upgradable
- **Open-Source Firmware:** Licensed under Apache-2.0 at [github.com/WeatherXM/wg1200-firmware](https://github.com/WeatherXM/wg1200-firmware)

### WG1200 Firmware Feature Highlights

Recent WG1200 firmware releases (up to `v0.8.37`) bring a rich local analytics, storage, and integration suite directly to the gateway:

- **Built-in Local Web Console (`http://<gateway-ip>/`):**
  - **Live Dashboard:** Real-time RF link telemetry, latest weather cards (including *Feels Like*, *Dew Point*, *Daily Rain* accumulation, and onboard barometer), and 15-minute high-frequency multi-axis trends.
  - **24-Hour Historical Weather Trends & Hourly Wind Ribbon:** Interactive 5-minute aggregated charts over the previous 24 hours (288 slots) featuring a speed-weighted **Hourly Prevailing Wind Direction Ribbon** (`N`, `NNE`, `SW`, etc.), dual-axis **Precipitation Rate & Cumulative** charts, color-coded summary pills (*Min / Avg / Max*, *Peak Gust*, *Prevailing Wind*, *3h Pressure Trend*, *Total Rain & Wet Time*), and synchronized crosshairs & drag-to-zoom across all charts.
  - **Bidirectional LCD ↔ Web Display Units Sync:** Change temperature (`°C`/`°F`), wind speed (`m/s`, `km/h`, `mph`, `ft/s`, `bft`, `kn`), precipitation (`mm`/`in`), or pressure (`hPa`, `mmHg`, `inHg`) units on either the touchscreen LCD or the Web Console (`POST /set_units`, `GET/POST /api/v1/units`) and both interfaces immediately update and rescale all live sparklines, dashboard cards, and historical charts.
- **microSD Weather History, Browser CSV Viewer & Safe Eject:**
  - **Browser CSV Viewer (`/sd/view`):** Inspect stored daily weather and metadata CSV files directly in your browser with interactive charts, hourly wind ribbons, searchable newest-first tables, and data-quality flag highlighting—without downloading files first.
  - **Safe Eject / Mount & Auto-Remount:** Dedicated **Eject SD Card** / **Mount SD Card** controls in the Web Console (`/sd/eject`, `/sd/mount`) and on the LCD touchscreen pause SPI writes for safe card removal and automatically detect physical card re-insertion (`EXPANDER_IO_SD_DET`) to remount and flush queued RAM history.
  - **Hardware SPI Diagnostics & Guided Formatting:** Pre-inspects card partition tables in raw SPI mode to detect unformatted or unsupported cards (e.g. exFAT/NTFS) without interrupting gateway operation, with capacity-based dynamic formatting ETA (`~4.2s/GB`) and command-level diagnostics (`/sd/diagnose`).
- **Home Assistant, Local REST API & AI Agent Support (`/llms.txt`):**
  - Broadcasts `_weatherxm._tcp` over mDNS on port 80 for automatic local discovery.
  - Exposes structured JSON endpoints (`/status`, `/api/v1/info`, `/api/v1/observations`, `/api/v1/history`, `/api/v1/units`), an interactive REST API explorer with a one-click **Home Assistant YAML generator**, and a machine-readable `/llms.txt` endpoint for AI coding and automation agents.
- **Meshtastic & MeshCore Off-Grid LoRa Beaconing:**
  - Shares the SX1262 LoRa radio via a phase-aligned post-RX radio lease and Listen-Before-Talk (Channel Activity Detection) to broadcast standardized **Meshtastic** (`Environment Telemetry`, `NodeInfo` with hardware X.509 certificate fingerprint, `DeviceMetrics`, and `Position` on `LongFast`) and **MeshCore** weather beacons to local mesh networks without missing 20-second station uplinks.
- **Smart Station Pairing & Live LoRa Packet Sniffer:**
  - Independently persisted **Cloud** and **Local** station profiles (`CLOUD`, `LOCAL`, `SCAN`, and `OFF` monitor-only mode), targeted **Pair on Reboot**, multi-phase autonomous fallback recovery, and a live **LoRa Packet Sniffer** (`/packet_log`) in the Web Console.
